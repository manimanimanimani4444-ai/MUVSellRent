# MUVSell Rent — плагин FunPay Cardinal

Перепродажа аренды Steam-аккаунтов с [muvsell.store](https://muvsell.store) на FunPay.

Покупатель оплачивает ваш лот на FunPay → плагин арендует аккаунт на MUVSell через API (списывает ваш баланс MUVSell по цене сайта) и сразу присылает логин и пароль в чат. Разница цен — ваш заработок.

## Что умеет

- Автовыдача логина и пароля сразу после оплаты
- Коды Steam Guard по команде покупателя
- Каждая покупка лота выдаёт новый аккаунт; продлить текущий — командой `!продление`: плагин создаёт временный лот на нужный срок, оплата добавляет время к тому же аккаунту
- Синхронизация наличия и цен с наценкой — общей, по категориям или у каждой привязки
- Автовыставление лотов с редактором текстов: в разделы игр, а также в Steam «Аккаунты с играми» и «Прочие игры» — любую игру на ваш выбор, на все сроки из настроек
- Статистика и прибыль, карантин проблемных лотов, уведомления, диагностика

## Установка

1. Нужен FunPay Cardinal (проверено на 0.1.17.15).
2. Скачайте [`MUVSellRent.py`](MUVSellRent.py) и положите в папку `plugins/` Cardinal, перезапустите его.
3. Зарегистрируйтесь на [muvsell.store](https://muvsell.store), пополните баланс и создайте API-ключ: **Профиль → API**.
4. В Telegram-боте вашего Cardinal: **Плагины → MUVSell Rent → Настройки** — вставьте API-ключ.

Карту разделов FunPay плагин скачивает с сайта сам, обновления плагина тоже приходят с сайта.

Если плагин пишет «нет связи с muvsell.store», значит сервер с Cardinal не может подключиться к сайту. Так бывает с частью зарубежных VPS: их адреса недоступны из России. Включите прокси: **Настройки → 🌐 Прокси MUVSell**.

## Команды покупателя

Повторная покупка лота выдаёт **новый** аккаунт. Продлить текущий можно только командой продления.

| Команда | Что делает |
|---|---|
| `!код` | Код Steam Guard |
| `!данные` | Логин и пароль ещё раз |
| `!время` | Сколько осталось аренды |
| `!продление 3` / `!продление 2д` | Продлить этот аккаунт на 3 часа / 2 дня: плагин создаст временный лот, оплата добавит время |
| `!кик`, `!пароль` | Выкинуть чужие сессии, сменить пароль (если продавец включил) |
| `!помощь` | Список команд |
